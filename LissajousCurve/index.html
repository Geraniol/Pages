李萨如图形 · 质数频率比矩阵

横轴与纵轴分别由两个简谐振动驱动，频率之比取不同的质数对。由于任意两个不同质数必然互质， 曲线的最小正周期恰为 2π：图形严格闭合、不会随时间缓慢翻滚——这正是质数比在示波器上 呈现出「干净、稳定」花样的原因（这一点已对表中全部组合数值验证）。矩阵中同为奇数的质数对 沿主对角线互为镜像。

x(t) = A·sin(p·t + δ)   ·   y(t) = B·sin(q·t)

质数比矩阵 p : q

闭合与最小周期

写成最简整数比 a : b（a ⟂ b）后，γ(t + T) = γ(t) 要求 aT 与 bT 同时为 2π 的整数倍；互质使最小正周期恰为 T = 2π。两个不同质数自动互质，所以矩阵中每个格子都是严格闭合的静止花样。

重复描迹：含 2 的那一行

闭合不等于「不重描」。在 δ = 90° 下，若 a 为偶、b 为奇， 则 γ(π − t) = γ(t) 恒成立，整条曲线会被描画两次——矩阵中 p = 2 那一行正是如此。而两个质数同为奇数时不存在这种对称， 曲线只走一遍，光点轨迹最「经济」。

自交节点的数量

这个数依赖具体的参数化与相位，没有统一定值：对一般的相位，互质 p, q 的曲线有 2pq − p − q 个二重点；在特殊相位下图形退化、被重复描画， 交点数随之减半（例如 x = cos pt, y = cos qt 在相位为 0 时是 (p−1)(q−1)/2）。 因此本表只呈现形状，不标注节点数。详见 MathOverflow 讨论 “Formula for number of intersection points for Lissajous curve?”。

对角线：退化情形

对角线上 p = q，比值为 1 : 1。此时曲线退化为圆（δ = 90°） 或直线段（δ = 0°/180°），不再具有频率比信息——真正的「质数比」只出现在非对角元。

相位差 δ 的作用

δ 控制曲线在矩形框内的「张开程度」，也是最容易改变图形观感的参数：δ = 90° 时图形最饱满， δ 趋于 0° 或 180° 时逐渐收拢成一条对角线。拖动上方滑块可以手动定格任意相位， 打开相位自动演化则会让全部 36 个格子一起缓慢变形（约 30 秒走完一圈）。

镜像对称只发生在奇数对

把 p 与 q 互换，只有在两者同为奇数时才恰好等于沿 y = x 的镜像——表中标了 ⇋ 镜像 的格子与其转置格互为镜像。 一旦含偶数的质数（也就是 2），转置后的图形会变成另一个形状，不再是简单翻转。

为什么用质数

若频率比为 6 : 4，化简为 3 : 2，图形与 3 : 2 完全相同—— 多余的公约数只让光点多绕几圈。用质数比可保证每个格子都是「新」花样，且周期最短、成像最稳定。
