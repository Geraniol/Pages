# TravelMap

把广州、深圳、香港，以及澳大利亚、新西兰值得一去的地方摊在一张 Leaflet 地图上：左侧按标签筛选，右侧地图联动，点卡片或图钉看详情——票价、开放时间、地区交通、优缺点与来源链接。

在线地址：<https://geraniol.github.io/Pages/TravelMap/>

纯静态站点，无后端、不上传任何数据；地图库与瓦片走 CDN，需要联网。

## 功能

- **五个地区**：广州 48 · 深圳 35 · 香港 58 · 澳大利亚 124 · 新西兰 30（2026-09 核验）。切换地区走 URL 锚点 `#gz` `#sz` `#hk` `#au` `#nz`，不刷新页面，数据按需加载。
- **筛选**：按标签筛（人文景观、自然风景、美食、商场、天文、军事……），另有「推荐景点」筛选键——它**不是标签**，判据是条目上的 `rank` 字段。
- **视图**：宽屏左右分栏；窄屏（≤768px）面板变成全屏卡片视图，默认收起，靠底部「地图 / 卡片」切换。
- **底图**：境内用高德（GCJ-02），澳新用 Esri 街道图（WGS-84）；瓦片加载失败会在图上给出提示。

## 文件与分层

| 文件 | 层 | 职责 |
|---|---|---|
| `index.html` | 框架 | 固定外壳：侧栏、地图容器、详情层与选地区层、底部视图切换 |
| `app.js` | 逻辑 | 图标表与标签体系、筛选、渲染、详情、路由、数据按需加载 |
| `main.css` | 样式 | 全部视觉：`:root` 设计变量、标签色、布局与断点 |
| `data.js` | 数据 | 地区索引，只有 `{ id, name, file }`，不含任何地点 |
| `data/<id>.js` | 数据 | 一个地区的全部兴趣点，自注册到 `window.CITY_DATA` |

外部依赖只有 Leaflet 1.9.4（unpkg CDN）；图标取自 lucide（ISC 许可），按名内联，不引整包、不用 emoji。

### 分层规范：每层只放本层的东西

| 层 | 只放 | 不放 |
|---|---|---|
| 框架 `index.html` | 固定结构、静态图标 | 地区数据、内联样式、渲染逻辑 |
| 逻辑 `app.js` | 图标表、标签体系、渲染、路由 | 地名、坐标、颜色与尺寸字面量 |
| 样式 `main.css` | 设计变量、颜色、布局 | JS 语法、数据 |
| 数据 `data*.js` | 纯数据字面量 | 函数、DOM、HTML 标签、样式 |

四条硬约束（都可脚本机械检查，见 `SKILL.md` 第八节）：

1. **一处一个值**：颜色只写在 `main.css` 的 `:root`，逻辑层用 `cssVar()` 读；尺寸同理——`--pin-md` 由 `app.js` 读取来决定标记大小，改 CSS 一处即可，不要在 JS 里再写一份。
2. **图标只定义一次**：由数据或运行时决定的图标（标签、链接、评价正负面）在 `app.js` 的 `ICONS`；框架自身静态外观的图标（如标题旁的下拉箭头）直接内联在 `index.html`。同一图形有两份定义，就是日后改一处不生效的来源。
3. **「推荐景点」不是标签**：判据是条目上的 `rank` 字段（`app.js` 的 `FLAGS`），所以数据文件里不该出现 `tags:["推荐景点"]`。
4. **注入的是变量，不是样式**：`style="--chip-c:${运行时取色}"` 合法（规则在 CSS、值按条目注入）；`style="padding:28px;color:#9c9cb0"` 是表现层漏进了逻辑层。

## 加一份新数据

数据分两级：`data.js` 只放索引，`data/<id>.js` 放该地区的全部地点，由 `app.js` 按需加载（选哪个加载哪个，加载过的缓存）。

加一个地区 = 新建 `data/<id>.js` + 在 `data.js` 的 `CITIES` 加一行 `{ id, name, file }`，其余文件都不用动。`id` 同时是 URL 锚点。

### 交给 skill 做

`SKILL.md` 就是这个目录里的 skill（带 frontmatter，可直接加载或安装），把「**定受众 → 定标签 → 收集地点 → 取坐标 → 收集评价 → 写数据文件 → 校验**」整套口径写死了：数据契约、每个字段的书写约定、取坐标的坐标系与主要失手方式、来源与 WAF 的实测结论、写文件的格式约定、验收清单。**加数据让它来写，人只做验收。**

对 AI 说的话，例如：

```text
读 TravelMap/SKILL.md，按它的流程给「顺德」做一份地图数据：
受众是周末两日游、广州出发的自驾客，标签以美食和自然风景为主。
数据写进 data/sd.js，并在 data.js 的 CITIES 里加一行。
写完跑第八节的校验和第九节的验收清单，把结果报给我。
```

同类说法：「再加一个城市」「把某个地点加进地图」「做一份境外地图」。

### 坐标系与底图（最容易错的一项）

| 地区 | 坐标 | `tiles` |
|---|---|---|
| 中国境内 | GCJ-02（与高德、腾讯瓦片一致） | 不用写，默认高德 |
| 境外 | WGS-84，**不要做任何转换** | **必填**，如 Esri 街道图 `…/World_Street_Map/MapServer/tile/{z}/{y}/{x}`（y 在前） |

境外必须换源，因为高德瓦片在境外基本是空白；换源时 URL 里**不能带 `{s}`**（默认源的 `webrd0{s}` 子域只对高德成立）。另外，旧做法里的 Carto 暗色底图现已需要 key，无 key 时它**不报错**，只返回写着 `API KEY REQUIRED` 的占位图，别再选它。详细结论见 `SKILL.md` 第四节。

### 三个最常写错的字段

`area` / `hours` / `fee` 是列表卡片的展示契约，不是备注栏：卡片只显示第一个分隔符**之前**的内容（`area` 取到 `·`、`fee` 取到 `；`、`hours` 取到 `（`），所以第一段要写成 10 字以内、能独立读懂的摘要，档位与淡旺季等细节一律放到分隔符之后。

另外：字符串里不要出现 `<` `>` `"`（渲染走 `innerHTML`，会破版），需要引号用 `「」`；空数组直接省略；文件换行统一 LF。

### 加新标签

一个标签 = 图标 + 颜色，两者分属两层，按情况选最小改法：

- **复用**已有图标名与已有颜色变量 → 只在该地区的 `extraTags` 里加一条，不动其他文件；
- **要新图形或新颜色** → 同时改两处：`app.js` 的 `ICONS` 加图形、`main.css` 的 `:root` 加颜色变量。缺一处不报错，只是静默走样：颜色变量缺 → 退成默认灰，图标名缺 → 渲染出没有图形的空 SVG；
- **多个地区共用** → 提到 `app.js` 的 `DEFAULT_TAGS`，别在每个数据文件里各写一遍。

## 维护

营业时间与票价变动最勤，每个数据文件的 `updated` 字段记核验年月。地点结业或搬迁的范式是**保留条目并显著标注**（名称加标记、费用写「已关闭」、首句警告，并给出替代选项），而不是删掉——既避免使用者白跑，也保留历史信息。展会与季节性活动的档期每年变，必须核对当年公告。详见 `SKILL.md` 第十节。
